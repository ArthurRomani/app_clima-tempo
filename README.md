# 🌦️ WeatherApp

Aplicativo de clima desenvolvido com React Native. Ele permite que o usuário busque e visualize a previsão do tempo de uma cidade selecionada.

## ✨ Funcionalidades

- 🔍 Busca pelo nome da cidade
- 🌡️ Exibição da temperatura atual
- 🌤️ Condições climáticas (ex: ensolarado, nublado)
- 💧 Umidade relativa do ar
- 🌬️ Velocidade do vento
- 🎨 Interface responsiva e de fácil utilização

## 🚀 Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [OpenWeatherMap API](https://openweathermap.org/)
- JavaScript (ES6+)
